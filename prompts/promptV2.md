# Prompt V2 — Processo de precificação (Criativo → Atendimento), com formato estruturado

## Contexto

Refinamento do prompt em [promptV1.md](promptV1.md): mesma tarefa (conectar conceito criativo a uma estimativa inicial de custo, reduzindo o vai-e-volta entre Criativo e Atendimento após a Samba ganhar uma concorrência), mas agora com um formato de saída explícito — fluxo, tabela de responsabilidades, exemplo prático e indicadores — para tornar o processo mais fácil de aplicar no dia a dia.

## Prompt

**TAREFA**
Crie um processo simples e prático para padronizar a precificação de projetos da Agência Samba depois que a agência ganha uma concorrência, conectando o conceito criativo a uma estimativa inicial de custo e reduzindo o vai-e-volta entre Criativo e Atendimento.

**AMOSTRA**
Um bom resultado deve funcionar como um fluxo que o time consiga aplicar no dia a dia. Por exemplo:
Briefing do cliente → conceito criativo → identificação dos elementos do projeto → estimativa inicial de custo → classificação do que é cobrável ou não → validação com Atendimento/Produção → orçamento final.
A proposta deve deixar claro quem participa de cada etapa, qual informação precisa ser definida e em que momento o orçamento deve ser revisado.

**FORMATO**
Apresente a resposta em:
1. Um fluxo com as etapas do processo em ordem.
2. Uma tabela mostrando, para cada etapa, o responsável, o que deve ser feito e qual é o resultado esperado.
3. Um exemplo prático de como um conceito criativo poderia ser transformado em uma estimativa inicial de custo.
4. Três indicadores simples para acompanhar se o novo processo está funcionando.

**LIMITE**
Não crie um sistema tecnológico complexo nem transforme o time criativo em uma equipe financeira. Não invente valores reais de custos ou preços da Samba. O objetivo é propor um processo simples que possa ser aplicado com as ferramentas e equipes que a agência já possui. Considere também que a Samba pode ter vários projetos acontecendo simultaneamente, como os seis projetos atuais para o Rock in Rio, e que o principal objetivo é reduzir o tempo entre ganhar a concorrência e ter o orçamento aprovado e liberado para o cliente.
